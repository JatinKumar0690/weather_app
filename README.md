# 🌤️ Weather Web Application

> A clean, responsive weather application that delivers real-time weather data and forecasts using a third-party API.


## 🌟 Features

*   **Real-Time Data**: Get current temperature, humidity, wind speed, and weather conditions for any city.
*   **Search Functionality**: Users can easily search for weather by city name.
*   **Dynamic UI**: The interface and weather icons update dynamically based on the current weather conditions.
*   **Responsive Design**: Built with a mobile-first approach ensuring a seamless experience across desktops, tablets, and smartphones.
*   **Error Handling**: Graceful error messages when a city is not found or the API request fails.
